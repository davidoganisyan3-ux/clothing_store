## Цель проекта

Учебный проект, созданный, чтобы на практике освоить бэкенд-разработку
на Java и Spring Boot и собрать работающий пример для портфолио.
Я хотел пройти путь от базы данных до защищённого API так, как это
делается в реальных проектах, а не ограничиться отдельными упражнениями.

## О проекте

REST API интернет-магазина одежды.

- Каталог: категории и товары, у каждого товара есть размеры
  с остатками на складе.
- Пользователи: регистрация, вход, пароли хранятся в виде хэшей (BCrypt).
- Заказы: оформление заказа выполняется в одной транзакции
  с проверкой остатков, у пользователя есть история заказов.
- Безопасность: вход по JWT-токену, проверка токена в фильтре
  Spring Security, роли USER и ADMIN. Добавлять товары может только
  администратор, обычный пользователь видит только свои заказы,
  администратор может смотреть заказы любого пользователя.
- Ошибки и валидация: входные данные проверяются, ошибки
  возвращаются в едином формате.
- Документация: Swagger UI со страницей всех эндпоинтов
  и кнопкой авторизации по токену.

## Чему я научился

- Проектировать структуру базы данных в PostgreSQL и работать с ней
  через Spring Data JPA.
- Строить REST API на Spring Boot: контроллеры, сервисы, репозитории.
- Использовать транзакции, чтобы заказ и списание остатков не рассинхронизировались.
- Валидировать входные данные и обрабатывать ошибки в одном месте.
- Хранить пароли безопасно и аутентифицировать пользователей по JWT.
- Писать собственный фильтр в Spring Security и настраивать
  правила доступа по ролям.
- Документировать API через Swagger (springdoc-openapi).
